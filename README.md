# Steamify Studio PRO — No-Code кастомизация клиента Steam

Steamify — десктопное приложение на базе **Tauri v2 (Rust)** и **React + TypeScript + Tailwind CSS**, спроектированное по принципам **Apple Design** и **Tasteful UI** для визуальной кастомизации интерфейса официального клиента Steam (CEF-слой).

---

## 🌟 Ключевые возможности

### 1. Онлайн-каталог тем из сети (Community Themes Store)
В приложение встроен полноценный каталог культовых скинов сообщества:
- **Fluent for Steam (Windows 11 Acrylic)** — фирменный стиль Windows 11 с эффектом полупрозрачности Mica и синим акцентом.
- **Catppuccin Mocha** — знаменитая пастельная палитра №1 в мире (мягкая лаванда, маув и бархатный фон).
- **Nordic Polar (Nord)** — оригинальная арктическая палитра Nord с ледяным цианом.
- **Gruvbox Dark Retro** — тёплая винтажная палитра с оттенками охры и состаренного дерева.
- **Tokyo Night Storm** — неоновые огни ночного мегаполиса (индиго, циан, аметист).
- **Discord Modern Blurple** — аутентичный интерфейс Discord с фирменным акцентом #5865F2.
- **One Dark Pro (Atom / VS Code)** — культовая тема разработчиков со сбалансированным контрастом.
- **Pure OLED Pitch Dark** — глубокий чёрный (#000000) для OLED-матриц.
- Фильтры по категориям, поиск по тегам, рейтинг звёзд и счётчик загрузок.
- Действия в 1 клик: **«Примерить»**, **«Сохранить в свои»** и **«Применить напрямую»**.

### 2. Бесшовное подключение к Steam
- **Умный диалог активации CEF:** если Steam запущен без режима отладки, Steamify автоматически предлагает перезапустить Steam с параметром `-cef-enable-debugging` и сразу применить выбранную тему.
- **Автоматический рестарт:** гарантированное завершение дерева процессов `steam.exe` и `steamwebhelper.exe` и запуск с флагом отладки.
- **Ярлык на Рабочем столе:** создание ярлыка «Steam (Кастомизация)» в 1 клик, чтобы Steam всегда запускался с поддержкой тем.
- **Авто-инъекция и Watcher:** стили сохраняются при переходе между страницами библиотеки и при перезапуске Steam.

### 3. Редактор и живой предпросмотр
- Тонкая настройка 8 цветов с быстрыми палитрами рекомендаций.
- Слайдеры скруглений карточек и кнопок (0–32px).
- Выбор шрифтов: системные + Google Fonts (`Inter`, `Plus Jakarta Sans`, `Space Grotesk`, `JetBrains Mono`, `Fira Code`, `Poppins` и др.).
- Скрытие блока «Что нового», нижней панели загрузки, компактный список игр.
- Размытие (Blur) и непрозрачность (Opacity) фонового изображения.
- Живой интерактивный макет Steam с нулевой задержкой отображения изменений.

### 4. Экспорт и сброс
- Экспорт папки темы для Millennium / SFP (`skin.json`, `webkit.css`, `libraryroot.custom.css`).
- Экспорт и импорт одиночных тем в файлы `.steamify`.
- Кнопка **«Сброс»**: моментальное снятие DOM-инъекций и восстановление файлов из автобэкапа.

## 🛠️ Запуск и сборка

### Режим разработки (Dev)
```bash
npm run tauri dev
```

### Сборка релизных установщиков
```bash
npm run tauri build
```
Готовые файлы:
- **Установщик NSIS (.exe, 2.54 МБ):**  
  `src-tauri/target/release/bundle/nsis/steamify_1.0.0_x64-setup.exe`
- **Пакет MSI (.msi, 3.80 МБ):**  
  `src-tauri/target/release/bundle/msi/steamify_1.0.0_x64_en-US.msi`
- **Автономный бинарник (.exe):**  
  `src-tauri/target/release/steamify.exe`
